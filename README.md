# Smoked by AI

Restaurant and bar picks by city, with the chef and critic quotes behind each. This plugin gives an assistant the guide at [smokedby.ai](https://smokedby.ai): a skill for how to answer from it, and its MCP server at `https://smokedby.ai/api/mcp`. No key and no account.

## Claude Code

```sh
claude plugin marketplace add daltonj/smokedby-plugin
claude plugin install smokedby@smokedby
```

## Codex

```sh
codex plugin marketplace add daltonj/smokedby-plugin
```

Then turn on Smoked by AI under Plugins.

## Try

- Where should I eat brisket in Austin?
- A romantic dinner in Rome near Trastevere.
- Late-night food in Glasgow.
